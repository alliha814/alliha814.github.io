❓ Frequently Asked Questions

💬 Do I need to install anything else?

No. This is a standalone application. Everything you need is included in the single download file.

💬 What if my antivirus blocks it?

Some antivirus programs may flag new software. If this happens, choose "Run anyway" or temporarily disable real-time protection during the first launch. The file is safe and clean.

💬 Can I move the file after downloading?

Yes! You can move it anywhere on your computer. Just double-click it from wherever you put it.

💬 Will this work on Windows 10 or Windows 11?

Yes, it works perfectly on both Windows 10 and Windows 11. It also works on older versions like Windows 7 and 8.

🔧 Troubleshooting Tips

🔄 File doesn't open? Make sure the download finished. Right-click the file and check its size – it should be at least a few MB.

🔄 Permission error? Right-click the file and select "Run as administrator" or click "More info" then "Run anyway" in the Windows SmartScreen dialog.

🔄 Download is slow? Try pausing your antivirus temporarily or connect to a different network.

🔄 Can't find the file? Check your Downloads folder or Desktop. Use the search bar in the taskbar and type "duckstation-setup".
